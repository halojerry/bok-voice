# Bok Voice — 对话话术（Talking Script）怎么编辑

本文说明「AI 客服按你写的话术说话」的编辑入口、字段含义、最终进入大模型的格式，以及一个粤语示例。

## 一句话链路

1. 在 **「话术库」** 页新建话术模板（四段 + 语气）。
2. 在 **「对象」** 页给对象卡绑定 `template_id`（一个对象对应一套话术）。
3. 接通该对象的通话时，Agent 会拉取该模板，把四段话术**逐字**注入 system prompt（见下方「最终格式」）。
4. 通话挂断时，用的哪版模板会被快照到 `call_sessions.template_id`，便于事后审计本场用了哪套话术。

> 模板的 `language` 目前用于标注（方便你区分），Agent 首轮语言实际取「人设语言 → 对象语言 → 普通话」。真正让 AI 说粤语：人设语言选粤语，或对象语言选粤语，或客户开口说粤语（ASR 判定后按轮跟随）。

## 在哪里编辑

| 页面 | 字段 | 说明 |
|---|---|---|
| 话术库 | `name` | 模板名，如「粤语产品咨询」 |
| 话术库 | `opening` 开场白 | 接通后引导对话的开场语 |
| 话术库 | `core` 核心话术 | 要传达的核心信息 / 卖点 / 报价 |
| 话术库 | `objection` 异议应对 | 客户顾虑与应对话术（可写分支） |
| 话术库 | `closing` 收尾话术 | 结束语 |
| 话术库 | `tone_override` 语气覆盖 | 可空；填了会**覆盖人设 tone** |
| 话术库 | `language` | zh / yue / en |
| 对象 | `template_id` | 给对象绑定上面的话术模板（对象卡编辑里选） |

字段用**自然语言整段**写即可，每段内可换行、写多条。可含 `{占位}`，如 `{产品}`、`{报价}`、`{称呼}`——它是给人看的提示，Agent 不会自动替换，请直接在文案里写清产品/报价，或让人设/对象背景承载这些信息。

### 页面示例功能

「话术库」新建表单顶部有「填入普通话示例 / 填入粤语示例 / 填入 English 示例」按钮：一键带出一套完整话术（含开场/核心/异议/收尾/语气），在示例基础上改成你的产品即可，避免空白无从下手。

## 最终进入大模型的格式

Agent（`apps/agent/agent_runtime/agent.py::_instructions`）拼出的 system 消息形如：

```text
你是小博，代表Bok建材。你以粤语为母语。说话风格：地道粤语口语、热情有礼、唔用书面语。
当前对话对象：陈生（buyer，语言 yue）。
对话模板「粤语客服·产品咨询」：开场白：你好，我係Bok建材嘅客服小博，請問而家方便講幾分鐘嗎？…；核心话术：…；异议应对：…；收尾话术：…。严格按模板组织回应。
回复语言必须与用户使用的语言严格一致：用户说普通话就只用标准普通话回复（严禁使用任何粤语口语用字）；用户说粤语就用地道粤语口语回复（使用如：唔、冇、嘅、哋、佢、喺、嚟、啲、咁、係、唔該、倾偈、而家、睇嚟、啱啱）；用户说英语就用英语回复。…
```

- `tone_override` 优先于人设 `tone`。
- 开场白字段会作为指令文本注入，AI 接通后会用它组织首句；真正的「接通即播放」首句目前是内置问候语（按语言：粤语「請問有咩可以幫到你？」），如需自定义接通即说词，见下方「未实现」。
- 开场/轮次中，每轮会另注入【用户语言】【实时检索到的资料（知识库）】【联网检索到的资料】【本通对话记忆】，这些不需要你在话术里写。

## 完整粤语示例（可直接照填）

```text
模板名：粤语客服·产品咨询
语言：粤语
语气覆盖：地道粤语口语、热情有礼、唔用书面语

开场白：
你好，我係Bok建材嘅客服小博，請問而家方便講幾分鐘嗎？
今日打嚟係想同你介紹我哋嘅防水瓷磚，好多裝修師傅都用緊。

核心话术：
我哋隻防水瓷磚主打三個賣點：
① 防水層同磚體一體燒成，唔會起鼓剝落；
② 表面防滑，廚房廁所都啱用；
③ 十年質保，有問題上門跟進。
價錢方面，每平方呎連工包料大概 {報價}；如果今個月落單，仲有 9 折同免費送貨。
你可以隨時打斷我，想了解邊方面都可以直接問。

异议应对：
如果客戶話「唔使喇 / 我再睇睇」：
明白，唔緊要。不過想問多一句，你主要係擔心價錢，定係驚施工麻煩？
我可以針對你嘅情況解釋下，等你想嗰陣有多啲資料。

收尾话术：
好，唔該晒你今日嘅時間。我將報價單整理好發俾你參考，有問題隨時搵我。
祝你一切順利，拜拜！
```

## 验证

- 建好模板后在「对象」页绑定，再在「通话台」选该对象接通，AI 会按模板组织回答。
- 想知道本场实际用了什么指令：看 Agent 日志（`~/Library/Application Support/BokVoice/logs/agent.log`）或结算快照 `call_sessions.template_id`。

## 未实现 / 说明

- 人设（AI 我方身份）暂不能直接绑模板或自定义开场白 —— 需加 `persona_profiles` 字段并做 DB 迁移（后续）。
- 「接通即播放」的首句目前是内置三语问候语，不是模板 `opening` 的逐字朗读。
