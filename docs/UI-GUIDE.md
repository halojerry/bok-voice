# Bok Voice 界面使用手册（页面级图解）

读者：话务员 / 主管 / 运营。本手册按「对着屏幕找得到、照着步骤点得动」编写，截图取自运行中的真机系统（1440×900）。**除 01b（话务员视角）外，其余截图均为 root（Platform Root）视角**，截图存于 `docs/assets/ui/`。界面文案以截图为准，点击后的行为以代码为准；两者有出入处在对应小节注明。

## 0. 名词速查（先看懂这几个词，后面的页面就好读了）

| 名词 | 意思 |
|---|---|
| 通话会话 | 一通电话的完整记录：转写、结算、状态都在里面 |
| 工作台 | 有两个含义：① 顶栏「进入工作台」= 接听/拨打电话的操作台；② 左侧导航「工作台」分组 = 会话/同传入口 |
| 对象 | AI 对话的「对方档案」——姓名、单号、地址、电话等，话术里的 {姓名} {快递单号} 就从这里取值 |
| 人设 | AI 的「我方身份」——称呼、公司、语气、音色 |
| 话术模板 | 分步骤的对话剧本；通话按步骤推进，可配意图和快答 |
| 直念步 | 话术里标了「电话接通先讲这一步」的步骤：进入该步时 AI 逐字照念（通知/赔偿承诺类合规内容用） |
| 分支 | 步骤里的「客户如果这样说 → AI 怎么做」应对行，可带动作（收线/通知人工/跳步/留步） |
| 意图 | 「听到某些话就做某事」的规则：关键词命中后播快答、跳步或通知人工 |
| 快答（罐头音） | 预先录好音频的标准回答：客户问法命中即直接播放，不经过模型现场生成 |
| 垫话 | 生成慢时先播的一句应承语（「嗯，我帮您查一下」），缓解等待 |
| 快路覆盖率 | 「照稿念」（脚本/录音直出）的回复占比，越高越快越稳 |
| 名册 · 认领池 | AI 捕获到的客户号码池，人工认领后跟进 |
| 意向码 / 处置 | 挂断时按通话事实给这通电话打的标签（如「已加WhatsApp」）与后续处理方式 |
| 演示档 | root 专用的云端 Realtime 演示通话模式（出境计费），普通业务不用 |
| 结算 | 挂断后自动生成纪要、沉淀知识、写通话结果的收尾动作 |

## 1. 这套系统长什么样

除登录页外，所有页面共用同一个骨架：

- **左侧导航栏**：按分组排列入口，底部有「收起导航」（收起后只剩图标轨，悬停图标显示名称）。截图 04/06/07/09/13 里导航只剩图标，就是点了「收起导航」后的样子。
- **顶栏**：左侧是当前页名；右侧依次是「● v0.1.0」（绿点=控制面在线，控制面失联时这里变成红字「控制面离线」）→ 当前登录人姓名 →「改密」→「退出」→ 黑色按钮「**进入工作台**」。
- **内容区**：页面主体。无权限访问的页面会显示「无权访问此页面，请联系主管开通权限」和一张「返回首页」卡。

「改密」点开是一个弹窗：填当前密码、新密码（至少 8 位）、确认新密码，点「修改并重新登录」——改成功后旧会话立刻作废，需用新密码重新登录。「退出」点了立即回登录页。

本手册的读法约定：

- 每页一节，配真机截图；「控件表」三列 = 界面上叫什么 ｜ 它是干什么的 ｜ 点下去会发生什么。
- 「操作步骤」是该页最高频的 2-4 个任务的编号动作；「常见坑」一行是实测最容易踩的地方。
- 截图未拍到但确实存在的弹窗/折叠卡，以「（截图未含，入口在 X 页的 Y 按钮）」标注。

### 三种角色看到的导航差异

导航按角色裁剪（对照截图 05-studio 顶部的 root 导航逐项列）：

| 导航分组 | 菜单项 | root（超级管理员） | admin（管理员/主管） | user（话务员） |
|---|---|---|---|---|
| 工作台 | 会话（/calls）、同传（/interpret） | 不显示（服务端仍放行，可输网址直达，作排障通道） | 显示（按其权限有效集） | 显示（需勾选对应页面键） |
| 运营 | 名册、外呼、对象、报表 | 不显示（同上） | 显示（报表需被授予） | 显示（报表默认关，主管可开） |
| AI 设置 | AI 工作站（/studio） | 不显示（同上） | 显示 | 显示（需话术键） |
| AI 设置 | 知识库、人设 | **显示**（截图 05 左侧「AI 设置」组） | root 下发了对应管理键才显示 | 永不显示 |
| 管理 | 主管台、员工、审计、设置 | **显示**（截图 05 左侧「管理」组） | root 下发了对应管理键才显示 | 永不显示 |
| 管理 | 节点 | **显示**（仅 root） | 永不显示 | 永不显示 |

要点：

- **root 是「平台控制台」形态**：导航里只有平台/管理面——截图 05-studio 左侧就是 root 的全部导航：「AI 设置」组（知识库/人设）+「管理」组（主管台/员工/节点/审计/设置），**运营页（会话/同传/名册/外呼/对象/报表/AI 工作站）不在 root 导航里**。root 要进话术与作业面：点顶栏「进入工作台」，或直接输入网址（如 `/studio/`、`/calls/`）——服务端对 root 全域放行，只是菜单不显示。**不要把 root 截图里的导航当成话务员会看到的样子**。
- **user 是「话务员台」形态**，导航以运营页为主。下图是话务员（演示话务员）登录后的真实界面：左侧「工作台」组（会话/同传）、「运营」组（名册/外呼/对象）、「AI 设置」组（AI 工作站）；该账号未开「报表」权限所以没有报表项；知识库/人设/主管台/员工/节点/审计/设置等平台管理页一概不显示。
- **admin 是「客户主管台」形态**：运营页全看（按有效集），管理页逐键由 root 下发，没下发就看不见——介于上两者之间。
- 本机单用户模式（未开认证）= 匿名登录，全部页面可见。
- 「找不到页面/无权访问」= 没权限，找 root 或主管开通（见附录）。

## 2. 逐页字典（按截图编号）

### 00 登录页

![登录页](assets/ui/00-login.png)

这页干什么：用主管分配的账号进入系统。谁用：所有人。

| 控件 | 作用 | 点了发生什么 |
|---|---|---|
| 用户名 / 密码 | 输入账号凭据 | 必填才能提交 |
| 登录 | 提交登录 | 成功=存令牌并跳到工作台首页；用户名或密码错误会红字提示 |
| 直接返回首页 | 链接 | 本机单用户模式（未开认证）无需登录，点了直接进系统 |

操作步骤：① 输入主管给的用户名和密码 → ② 点「登录」→ ③ 登录后默认落在工作台首页。

常见坑：连续输错不是锁定而是提示「用户名或密码错误」；忘记密码找主管在「员工」页重置。

### 01 通话会话（/calls）

![通话会话](assets/ui/01-calls.png)

这页干什么：全部通话的列表与入口——进历史/活跃会话，或发起新会话。谁用：话务员日常主页面、主管回查。

| 控件 | 作用 | 点了发生什么 |
|---|---|---|
| 清空已结束历史 | 清理列表 | 弹确认框，确认后删除所有「已结束」通话（不可恢复） |
| ＋ 新建通话 | 发起新通话 | 跳「/calls/new」通话工作台 |
| ▶ 意向规则 | 折叠卡（挂断时按通话事实判定意向码/标签/处置） | 展开见表后说明 |
| 进入 →（行内青字） | 打开这通通话 | 同页内嵌通话工作台，可回放转写/结算 |
| 删除（行内红字） | 删单条记录 | 弹确认框；转写与结算一并删除 |
| 补结算（仅已结束行） | 漏走挂断结算的通话手动补一次 | 弹确认框；生成纪要/知识沉淀，完成后刷新列表 |
| 再拨（仅已结束行） | 用同一对象再打一通 | 跳工作台并预选该对象 |
| 显示更多 | 列表翻页 | 每次多显示 100 通（默认最新 50 通） |

行内信息：对象名 +（演示档徽标/WhatsApp 徽标）·「真实业务/训练/演示档 · 语言 · 时间」· 通话 id + 轮数与均延迟 · 状态点（进行中绿/振铃黄/已暂停蓝/已结束灰/失败红）。进行中的通话每 4 秒自动刷新，WhatsApp 待对接时整行闪烁。从主管台横幅点「进入工作台」也会落到本页并自动展开那通（`/calls?call=<id>`）。

点「进入」后是**同页内嵌的通话工作台**（截图未含）：左侧对象档案与人设摘要，右侧转写流与「接通/挂断」主控；已结束的通话在这里看转写回放与结算卡（刚挂断时结算可能还在后台生成，页面会自动重试几次再展示，稍等即可，不用刷新）。点「← 返回列表」回列表，列表立即刷新那通的最新状态。

意向规则折叠卡（截图顶部「▶ 意向规则」，展开后是表格+弹窗；studio「客户意向」tab 是同一张卡）：可新建规则——名称、意向码、标签、处置（可选）、优先级（数字小先命中）、启用开关、命中条件（每行=事实下拉/比较符/值，全部成立才判中，事实含时长/轮数/到达步数/是否捕获号码等 12 键）；主管还可建「全局（对所有账号生效）」规则。挂断时按优先级取第一条命中的启用规则写进通话记录。

操作步骤：① 回听一通：点行内「进入」→ 看转写/结算 → 点「← 返回列表」；② 补纪要：找已结束行点「补结算」；③ 再打一通：点「再拨」。

常见坑：列表只显示最近 50 通，老通话点「显示更多」；「删除」与「清空已结束历史」都不可恢复。

### 02 名册 · 认领池（/roster）

![名册认领池](assets/ui/02-roster.png)

这页干什么：AI 从通话里捕获到的客户联系方式汇聚成池，供人工认领跟进。谁用：话务员（认领）、主管（督办）。

| 控件 | 作用 | 点了发生什么 |
|---|---|---|
| 全部状态 / 全部渠道 | 筛选下拉 | 状态=待认领/已认领/已对接；渠道=WhatsApp/微信 |
| 刷新 | 重拉列表 | 显示最新名册 |
| 复制（行内） | 复制号码 | 写入剪贴板，按钮短暂变「已复制」 |
| 认领（待认领行） | 把条目认领到自己名下 | 状态变「已认领」，认领人显示自己 |
| 标已对接 / 释放（已认领行） | 完成跟进 / 放弃认领 | 「标已对接」→已对接；「释放」→回到待认领 |
| 撤销（已对接行） | 误操作回退 | 状态退回「已认领」 |

列含义：客户=对象名；渠道=微信/WhatsApp；号码=捕获到的号码；摘要=客户原话或通话摘要（截断的悬停可见全文）；来源=产生这条的通话链接（点击进 /calls）。

操作步骤：① 筛「待认领」→ ② 「复制」号码、点「认领」→ ③ 按摘要回听来源通话 → ④ 跟进完点「标已对接」。

常见坑：同一位客户可能因多通通话出现多行，认领处理一行不影响其它行。

### 03 AI 人设（/personas）

![AI 人设](assets/ui/03-personas.png)

这页干什么：维护「我方是谁」——AI 的称呼、公司、说话风格、发音（音色/参考音频）。谁用：主管。

| 控件 | 作用 | 点了发生什么 |
|---|---|---|
| 编辑 / 删除（每条人设） | 维护人设 | 编辑载入右侧表单；删除弹确认框 |
| 称呼 / 代表公司 / 风格描述 | 人设三要素 | 例：小博 / Bok 建材 / 「专业、温和、简洁；适当使用敬语…」 |
| AI 使用语言（普通话/粤语/English 按钮） | 决定 AI 开场语言与默认表达 | 单选高亮 |
| 语音引擎（下拉） | 本地 Qwen3 或云端 MiniMax/火山 | 选云端=整场固定一把声（不随语言换声），并出现「AI 音色」单选 |
| 为该语言选音色（普/粤/English 页签 + 下拉） | 本地引擎时按语言配声 | 下拉含预置音色与克隆音色 |
| 参考音频对应的文字 | 录音/上传参考音频时必填的文稿 | 配合下方录音/上传控件做音色克隆 |
| 试听 | 试播当前音色 | 合成一段示例语音播放 |

保存人设且音色相关字段有变化时，系统会自动在后台重物化这个人的开场白/垫话/快答罐头录音（跑完才生效，无需手动操作）。

操作步骤：① 新建：右侧填称呼/公司/风格 → ② 选语言与引擎/音色 → ③（可选）录参考音频做克隆 → ④ 保存后到工作台选用该人设。

常见坑：换了人设音色后，已物化的罐头录音要等后台重录完成才会用新声播；「人设若单独绑定音色，优先于设置页全局音色」。

### 04 话术库（/templates，已移出主导航）

![话术库](assets/ui/04-templates.png)

这页干什么：话术模板的老版列表+新建页（共享徽标、分步预览、编辑/删除、示例填入）。**2026-09-20 起内容整合进 AI 工作站，本页已不在左侧导航**——路由保留，可从 AI 工作站或直接输网址进入；日常编辑请用 AI 工作站（见第 3 节）。

| 控件 | 作用 | 点了发生什么 |
|---|---|---|
| 编辑 / 删除（每套话术） | 维护模板 | 编辑载入右侧表单；删除弹确认框 |
| ＋加一步 | 分步话术加一段 | 文本框内追加一节 |
| 从表格粘贴导入 ▾ | 把表格数据一键变成分步话术 | 下拉里还有「填入普通话/粤语/English 话术示例」三个按钮 |
| 旧式四段话术（展开 ▾） | 兼容历史的开场/核心/异议/收尾格式 | 展开后填写，保存时自动转分步 |
| 语气覆盖（可选） | 覆盖人设的语气 | 留空=用人设 |
| 识别热词（可选，本套话术专属） | 提升语音识别对专名的准确率 | 逗号/顿号/分号分隔，数字串会被忽略 |

操作步骤：① 新建：点示例按钮得骨架 → ② 改成自己的分步话术 → ③ 保存后到 AI 工作站继续配意图/发布。

常见坑：在本页改完话术只是草稿——要让新通话按新版讲，必须去 AI 工作站点「发布」。

> 截图与代码差异说明：截图中未见「全部/我的/共享」归属页签——话务员（user）视角才会出现；主管视角直接看全部，与代码一致。

### 06 快答库 · 列表（/qa，已移出主导航）

![快答库列表](assets/ui/06-qa.png)

这页干什么：常见问法的「即答条目」——客户问到就直播标准答案录音，跳过模型生成。谁用：话务员（建自己的）、主管（管全部）。与画布同页切换；本页同样已移出主导航，日常入口=AI 工作站「问答库」tab / 问答画布。

| 控件 | 作用 | 点了发生什么 |
|---|---|---|
| 列表 / 画布 | 视图切换 | 见下节（07） |
| 编辑 / 停用 / 删除（每条） | 维护条目 | 停用=通话不再命中（按钮变「启用」）；删除弹确认框 |
| 归属（下拉，主管可见） | 共享（全账号）/ 指派给成员 | 改归属立即保存 |
| 新建快答条目（右侧表单） | 建新条目 | 见下 |

新建表单字段：客户问法（如：点样查物流？；命中按**字面措辞**判定，客户说法不同就多建几条）、标准回答（命中后直接播放的整句回答，按通话语言写）、语言（普通话/粤语/English）、生效范围（全程通用/指定步骤）、音色覆盖（留空=当前人设音色）、匹配优先级（0-1000，默认 10，数字越小越优先，只在同轮多条命中时决定谁）、启用开关 →「创建条目」。

操作步骤：① 把客户最常问的原话写进「客户问法」→ ② 写一句完整「标准回答」→ ③ 创建后找主管补录音（试听有音才算生效）。

常见坑：命中只认字面措辞——客户换个说法就不中，同义问法要多建几条；改了答案文本，旧录音即失效，需重新补录。

### 07 快答库 · 画布

![快答库画布](assets/ui/07-qa-canvas.png)

这页干什么：以某套话术为骨架的快答全景图——步骤主线上挂着问答条目、同义簇和意图节点，拖线即配置。谁用：主管为主。

| 控件 | 作用 | 点了发生什么 |
|---|---|---|
| 模板下拉（demo-演示话术-赔偿通知） | 切换骨架话术 | 画布换成该话术的步骤线 |

### 3.2 工作台态总览与「应用 / 发布」

![AI 工作站](assets/ui/05-studio.png)

顶栏从左到右：「← 返回列表」→ 模板名 + 语言徽标 → 右侧全局状态：**未保存**（琥珀圆点闪烁，主流程有改动未应用）/ **已保存 ✓** /「应用」按钮（有改动才亮）/「发布」按钮。

- **应用** = 把主流程的修改保存为草稿（唯一保存入口，只写话术步骤）。
- **发布** = 把「已保存」的版本冻结为正式版，**之后拨出的电话都按这个版本讲**；有未应用的修改会先弹窗提醒先「应用」。发布不影响在途通话。

八个页签：主流程 / 意图管理 / 问答库 / 变量设定 / 客户意向 / 录音沉淀 / 通话日志 / 场景学习（「场景学习」仅对有报表权限的人显示）。

常见坑：改完不点「应用」就返回会弹确认（丢修改提醒）；「发布」前确认改动已应用——发布的是已保存版本。

### 3.3 主流程 tab：画布（推荐）/ 列表编辑 双视图

画布（截图默认）：自上而下的步骤卡=通话顺序，连线「默认推进」。每张步卡片显示：步号+目的（如「1 确认身份」）、AI 说的话预览、深色徽标「● 电话接通先讲这一步」（=直念步：进入该步当轮逐字照念，如通知/赔偿承诺）或「逐字照念」标注、以及「客户这样说时有专门应对」分支行（如「说不是本人」）。左侧工具条 +/−/适应/锁定；「这个话术还没有设置意图…去『意图管理』添加 →」是空图提示。

**点任一步卡打开「第 N 步：AI 怎么说」抽屉**（右侧滑出），三件结构化编辑：

- **主要内容**：这步的正稿（进该步首轮后 AI 会结合着讲，不会逐字照念，除非标了直念）。
- **应对**（客户如果这样说 → AI 怎么做，每条一个应对）：条件（客户原话关键词）+ **动作下拉**（按内容回答（默认）/ 礼貌收线=道歉再见后结束通话 / 通知人工=给坐席打铃但 AI 照常应答不打断 / 跳到第 N 步 / 留在本步）+ 应答文本 + 录音状态点 + 「补录」按钮（给这条应对补罐头音频，客户这样说时直接播录音更快更稳）。画布上分支行会按动作显示彩色徽标：收线红 / 转人工蓝 / 跳步琥珀 / 留步紫。
- **给 AI 的补充提醒**：每次都要记住的事实（如必讲的号码）。
- 「＋ 加一条应对」新增分支。抽屉关闭不丢修改——统一走顶栏「应用」保存。

列表编辑视图：按步骤列表批量改文字，底部另有「模板设置」折叠卡（名称/语言/语气/热词，**有独立保存按钮**，不占用「应用」）。两个视图编辑的是同一份草稿，切换不丢。

操作步骤：① 点一步卡 → ② 在抽屉里改正稿/加分支（选动作、写应答）→ ③ 关抽屉 → ④ 顶栏「应用」→ ⑤ 全部改完点「发布」。

常见坑：画布只管「怎么讲」，改完不点「应用」=白改；「发布」才是让新通话生效的那一步。

### 3.4 意图管理 tab

表格+弹窗直编话术意图图：意图=名称+触发关键词（听到即触发，优先级小者先，可限定生效步骤、每通至多一次）+绑定动作（播快答[可加「播完后跳到」第 N 步] / 跳到某步 / 通知人工）+可选判据（关键词未中时后台大模型按判据补判模糊说法）。还提供按话术语言一键导入种子意图包。与问答画布（07）编辑的是同一份图。

操作步骤：① 「＋ 新建意图」→ ② 填名称与触发关键词（按客户原话写）→ ③ 加绑定动作（如播快答+播完跳到第 4 步）→ ④ 保存整图。

常见坑：关键词是字面匹配，客户换个说法不命中——同一意思多写几个关键词；「通知人工」只打铃不打断通话，AI 会继续应答。

### 3.5 问答库 tab

本模板作用域的快答条目表格+弹窗（同 06 页表单：问法/标准回答/语言/生效步骤/音色覆盖/优先级/启用），建完到「录音沉淀」看录音状态。

操作步骤：① 新建条目（问法抄客户原话）→ ② 保存 → ③ 切「录音沉淀」tab 看是否「缺录音」→ ④ 缺则去问答画布右键补录。

常见坑：新条目没录音等于没生效——快答命中后播的是录音，不是文字。

### 3.6 变量设定 tab

占位符目录与预览：列出本话术可用的变量（如 {姓名} {快递单号} {tracking_tail} {聯絡方式}…）、标出无效/写错的占位符告警、并可按对象预览渲染结果。语义与话术引擎同源——这里告警的占位符在通话里就会念出错。

操作步骤：① 打开 tab 对照目录检查话术里的占位符拼写 → ② 选一个真实对象点预览，看替换效果。

常见坑：变量名写错话术里会原样念出「{姓名}」两个汉字——以本 tab 的目录拼写为准。

### 3.7 客户意向 tab

与 /calls 页顶部的「意向规则」折叠卡是同一张卡（账号级规则面）：挂断时按通话事实（时长/轮数/到达步数/是否捕获号码等 12 类）判定意向码/标签/处置，命中即写进通话记录。表格+弹窗编辑，主管可建全局规则。

操作步骤：① 「新建规则」→ ② 加条件（如「已捕获号码 = true」）→ ③ 填意向码与处置 → ④ 保存并保持启用。

常见坑：条件全部成立才判中，别把互斥条件写进同一条；优先级小的先命中，想让某条规则优先生效就给它更小的数字。

### 3.8 录音沉淀 tab

上半是罐头音试听卡（开场白/垫话/快答的物化音频试听）；下半是**挂步骤的问答条目状态面**：每条显示「第 N 步 · 语言」+ 录音徽标（绿「录音✓」/琥珀「缺录音」）。页面提示：补录/重新录音请前往**问答画布**（右键条目「重新录音」）；分支录音在主流程画布的答法抽屉里「补录」。

操作步骤：① 进 tab 扫一遍琥珀「缺录音」→ ② 点页面里的「问答画布」链接 → ③ 右键对应条目「重新录音」。

常见坑：录音是按「答案文本」生成的——改了答案文字，这里的「录音✓」会变回「缺录音」，要重新补录。

### 3.9 通话日志 tab

按本模板过滤的通话列表（最新 50 通）：状态点+状态、语言、处置（意向码）、WhatsApp 徽标、通话 id 与时间；点「查看 →」跳 `/calls?call=<id>` 直接打开那通的工作台。

操作步骤：① 按时间从上往下找目标通话 → ② 「查看 →」回听/看转写。

常见坑：这里只显示挂了本模板的通话——跨模板找通话去 /calls 全量列表。

### 3.10 场景学习 tab（学习闭环驾驶舱）

![场景学习](assets/ui/05b-studio-study.png)

自上而下四块：

1. **话术优化分析（StudyTab 上半）**——「高频问题（对象议题聚合）」TOP10（截图：赔偿方案·提及 13 次…）与「共 N 通对话 · N 轮对话」总口径；接着「高频问答对挖掘（TOP N）」：每条=客户原话→AI 当时的高频答法+「语言 · N 命中」。
2. **AI 聚类采纳（StudyTab 下半）**——点「生成聚类计划」（本地大模型把挖掘候选对着现有词条归类，约十几秒），出三组勾选清单：**变体 → 并入既有词条**（按候选原话入库、继承既有答案）/ **新词条** / **丢弃（只读）**。勾选后点「采纳选中（N）」入库；入库后新词条需补录罐头音才真正生效（问答画布右键重新录音，或主管在设置页触发）。需要问答库权限才能生成/采纳。注意：生成与采纳必须同参数，中途改过条件要「重新生成聚类计划」再采纳。
3. **GapMining：快路覆盖率 + would-hit 汇总条**——「快路覆盖率」看「照稿念的回复占比」大数字 + 三个小卡（脚本/录音直出、AI 现场组织、回复轮合计），占比越高回答越快越稳，可点「按来源细分」看明细。其上的 **would-hit 汇总条**（喂库收益信号）读法：大数字 X% =「漏网问法里已有词条能直接接住的占比」，旁边两卡=漏网问法组数 / 已有词条覆盖数——把漏网问法采集成词条，这个数字就会涨；显示「无漏网」=最近通话没有反复出现的现场组织问法。
4. **漏网轮候选（三段式主体）**——「客户这么说，AI 是现场组织的」清单：每条=客户原话、出现 N 轮 · 涉及 N 通通话 · 话术第 N 步 · 语言、AI 当时说的原句、可回听通话 id。每句话有三种教法（确认后才生效）：
   - **采集为问答词条**（需问答库权限）：弹「确认采集」，答案预填 AI 当时说的话、**可先改再入库**；已采集的显示绿字「✓ 已采集」。
   - **做成话术分支**（需话术权限）：给某一步追加「如果客户…→就…」的应对行，应答可先改再存；已存在等价分支的显示为不可采纳并给原因（不会从画面消失）。
   - **做成意图词**（需话术权限）：给既有意图加触发关键词，同样可先改再存、重复时不可采纳。
   - 采纳提示会说明：改动只进**草稿**——记得去话术页「发布」才会生效。
5. **已入库快速回答的体检**（通知面）——「哪里该改、哪里可以删」：顶部摘要「改答案 N 条、建议删 N 条」；每条提案带人话标题/明细/次数，动作二选一：「删掉这条」（如从未被问过、客户报数字直接被绕过的词条）→「确认删掉」；「改这条答案」（如播了快答客户又问一遍、入库后从未命中）→ 弹窗改答案「确认改答案」。改答案会使旧录音失效：管理员操作会按批自动触发补录音；普通账号会提示需要找管理员补录。

常见坑：本 tab 需要「报表」权限；聚类的 dry 计划有过期时间——生成后放置太久再点采纳会被要求重新生成；体检里「从未命中」可能是词条被更高优先级条目抢了出场，删前看明细两条可能原因。
