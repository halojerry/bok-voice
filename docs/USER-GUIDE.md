# Bok Voice 使用说明书

| 项 | 值 |
|---|---|
| 文档版本 | 2026-09-26 |
| 读者 | 话务员（user）· 话务主管/运营（admin）· 演示者（销售/交付，root） |
| 配套文档 | 与 docs/DELIVERY-MANUAL.md（交付工程师手册，含部署/权限面/故障详表）、docs/UI-GUIDE.md（页面级图解手册，另册）配套 |
| 事实来源 | 全部操作取自 Web 界面真实功能；界面没有的功能本文不写 |

> 两句话认识产品：
> **A 线（语音客服）**——AI 按一套「话术」分步和客户通话：听（实时转写）→ 想（本地大模型）→ 说（合成语音），
> 通话全程有字幕，挂断自动出纪要，捕获到的客户号码自动进名册。
> **B 线（同传）**——两人各讲各的语言，AI 边听边译，字幕与译文语音实时出。

> 本手册**按场景组织**：每节说清「谁、什么时候、一步一步做什么、做完看到什么、下一步」。
> 页面上每个按钮的图解见另册 UI 手册；部署、账号开通、权限下发见交付手册。

## 0. 角色速览：你能看到什么

| 角色 | 登录后能看到 | 典型工作 |
|---|---|---|
| 话务员（user） | 工作台（会话/同传）+ 名册/外呼/对象（按主管授予）+ AI 工作站与快答库 | 建单通话、跟进名册、喂词条、改话术草稿 |
| 主管/运营（admin） | 话务员全部 + 被下发的管理页（主管台/员工/审计/设置/知识库/人设） | 盯盘打铃、旁听接管、管人设与音色、查审计 |
| 演示者（root） | 纯平台面（节点/授权/模型路由）+ 全部数据（服务端全域可达，排障用） | 演示档建单、平台管理 |
| 未登录（单机自用） | 全部页面，数据落在默认账号 | 单机试用 |

- 侧边栏按角色自动过滤：看不到某个菜单 = 没有对应权限，属正常，找主管开通。
- 话术和快答词条有「归属」：话务员建的原则上归本人（列表显示「我的」），主管建的「共享」给大家；
  共享条目话务员只能看不能改，别人的条目对你不可见。
- 主管改了你的权限，对你**当下打开的页面立即生效**（不用重新登录）。

## 1. 登录与首页导航

**谁**：所有人。**什么时候**：每天上班第一件事；密码到期或换电脑时。

1. 浏览器打开公司提供的网址，进入登录页。
2. 输入主管分配的**用户名**和**密码**，点登录。
3. 登录成功进入**首页仪表盘**：今日呼叫、客户接通率、今日接通量、标记统计（通话结果/WhatsApp）等大数卡片。
4. 左侧导航分四组：**工作台**（会话、同传）、**运营**（名册、外呼、对象、报表）、
   **AI 设置**（AI 工作站、知识库、人设）、**管理**（主管台、员工、节点、审计、设置）。
5. **修改自己密码**：右上角「改密」→ 填当前密码 + 新密码（至少 8 位）+ 再输一遍 → 确认。
   改成功会自动退出，用新密码重新登录即可。所有角色都能自助改密。
6. **退出**：右上角退出按钮。
7. 登录过期时，页面会自动跳回登录页，重新登录即可，数据不会丢。

单机自用形态（本机部署、未开启登录）打开网址即用，无需登录。

**常见坑**：新建账号初始密码找主管要；「报表」默认对话务员关闭，看不到不是坏了，需要主管授予。

## 2. 话务员日常：接打一通电话

**谁**：话务员。**什么时候**：接待一位客户、或回访某位对象时。

### 2.1 通话前：建档与建单

1. 先确认客户已在「对象」页有档（没有就先按 §3.2 建档）。
2. 侧边栏「会话」→ 右上角「**新建通话**」；对象页行内「**发起新通话**」也直达这里并自动预选该对象
   （会话列表已结束的行则叫「再拨」）。
3. 在新建页左侧：
   - **对象**：下拉选客户（右侧会显示该客户档案、历史主题、绑定话术）。
   - **人设**：选我方 AI 用哪套身份与音色（留空 = 默认人设）。
   - **模式**：一般选「**真实业务**」；「**训练**」= 自己演练话术用，不影响真实客户；
     「演示档」仅演示账号可见（见 §9）。
   - 通话语言自动跟随对象/人设的设置，不用手选。
4. 点「**接通**」，浏览器会请求麦克风权限——选「允许」。
   状态灯依次变为：连接中 → 初始化 → 聆听中，AI 随即开口讲开场白（开场白内容=话术第 1 步）。

### 2.2 通话中：看什么

| 区域 | 内容 | 怎么用 |
|---|---|---|
| 中栏·字幕时间线 | 客户/AI 每句话实时上屏，分色显示 | 核对 AI 有没有听错；客户说的关键信息（号码/单号）在字幕里能回看 |
| 中栏·状态灯 | 聆听中 / 思考中 / 说话中 | AI「思考中」稍等即可；想打断就直接开口说，AI 会停下听你讲 |
| 右栏·设备卡 | 麦克风/扬声器选择 | 听不见或对方听不见时先来这里换设备 |
| 右栏·服务状态 | 转写/大模型/合成等引擎连接灯 | 全绿=链路正常 |
| 中栏顶·WhatsApp 横幅 | 客户报出号码后数秒内弹出「已拿到号码」+ 大字号码 | 点「复制号码」发给跟进同事；处理完点「标记已对接」收起横幅 |

- WhatsApp 横幅有两种状态：「**已拿到号码**」（号码已捕获，可复制）和「**客户已应承加**」
  （客户答应了但还没报号，横幅提示等待中）。
- 会话列表里，正在通话且 WhatsApp 待对接的行会闪烁提醒，主管台同步可见。
- 客户**长时间不说话**，AI 会主动关心一句（沉默提醒）；再无回应会自动礼貌收线，不会无限挂着。

### 2.3 挂断后：看什么

1. 点「**挂断**」结束通话。右栏「结算」区随即出现：
   - **纪要摘要**：这通讲了什么；
   - **本轮新沉淀话题**：自动归入该客户的档案主题；
   - 通话文档/结算文档路径。
   这些自动沉淀进对象档案，下次和同一位客户通话时 AI 记得上下文。
2. 回到会话列表（最新优先）：每行显示状态、轮数、平均延迟；已结束的行有：
   - 点行 → 打开**转写回放**（逐轮文字记录，客户/AI 分色）。
   - 「**补结算**」：挂断时没生成纪要（如异常中断）可手动补一次。
   - 「**再拨**」：用同一对象直接发起新通话。
3. 客户号码被捕获后会自动进入「**名册**」认领池，按 §3.1 认领跟进。
4. 不想留痕的测试通话：行内「删除」可删单条；右上「清空已结束历史」批量清理（不可恢复）。

> 说明：当前版本**没有通话录音回放**功能，通话记录只有文字转写与结算纪要。

### 2.4 通话中的主管按钮

进入历史或在途通话时，工作台右上会出现「暂停 AI / 恢复 AI / 接管 / 转人工」——
这是**主管操作**（见 §7），话务员点击会提示无权限，属正常。

**下一步**：号码进了名册就去认领；客户提的新问题反复出现，就去 §5 喂进快答库。

**常见坑**：「新建通话」里没有对象可选=还没建档；接通后完全无声，先检查浏览器是否拒绝了麦克风权限、右栏扬声器选对没有。

## 3. 话务员日常：名册与人设

### 3.1 名册：认领捕获到的客户号码

**谁**：话务员。**什么时候**：通话中捕获到客户 WhatsApp/微信号码后跟进。

1. 侧边栏「**名册**」→ 认领池。通话中捕获的号码自动入池，状态「**待认领**」。
2. 点「**认领**」→ 状态变「已认领」，号码归属你（别人看到就先到先得）。
3. 点「**复制**」拿号码去加客户；跟进完成点「**标已对接**」。
4. 认领错了点「**释放**」放回池子；「已对接」的条目可「撤销」退回重办。
5. 顶部可按状态筛选：待认领 / 已认领 / 已对接。

**下一步**：跟进后需要再联系客户的，回「对象」页确认档案完整后发起通话。

**常见坑**：待认领的号码大家都能看到，先到先得——看到就尽快认领，别攒着。

### 3.2 对象：客户档案

**谁**：话务员。**什么时候**：接待新客户、客户信息变化时。

1. 侧边栏「**对象**」→ 右侧表单「新建对象」，逐项填写：

| 字段 | 填什么 |
|---|---|
| 姓名 | 客户称呼（AI 全程这么叫；也用于匹配话术变量 {姓名}） |
| 角色 | 采购商 / 客户经理 / 经销商 |
| 语言 | 中文 / 粤语 / 英语（决定整通通话语言与 AI 音色，中途不换语） |
| 背景 | 一两句客户情况（AI 通话时会参考） |
| 电话 | 外呼用（可选） |
| 快递单号 / 物流公司 / 地址 | 话术变量取值来源（{单号} 等） |
| 联系渠道 | 微信或 WhatsApp；留空按语言自动默认（话术里用 {联系方式} 引用，换渠道不用改话术） |
| 绑定话术 | 这位客户默认用哪套话术（可选；外呼战役未指定话术时也用这份） |

2. 点保存，列表立即出现该对象；顶部搜索框可按名字过滤。
3. **批量建档**：点「导入」展开文本框，从 Excel 直接粘贴表格
   （首行需含「姓名」表头，支持列：快递单号/物流公司/收货地址/电话，每行一个人）→ 导入后提示成功条数。
4. 修改：点行内「编辑」；勾选多行可批量删除（会连同该对象的通话转写一起删，慎用）。
5. 行内「**立即外呼**」：用该对象电话发起一通外呼（需管理员已配置外呼线路）。

**常见坑**：语言选错=整通通话语言错（开场白都会换成另一种语言）；批量导入没解析到行=首行缺「姓名」表头。

### 3.3 人设与音色（主管/管理面）

**谁**：主管（人设页在管理面；话务员看不到属正常）。**什么时候**：新开一条业务线、要换 AI 声音时。

1. 侧边栏「AI 设置 → **人设**」→ 新建/编辑。填名称、公司、语气、语言。
2. 下方**音色区**给这路人设挑一把声音，三种来源：
   - **预置音色**：云端音色目录，按人设语言自动过滤（英文人设只见英文音色）；
   - **已克隆音色**：你们自己克隆的声音（见第 4 步）；
   - **本地音色**：随本机引擎分发的预置声。
3. 选好后点「**试听**」确认听感，再保存。试听可切换试听语言。
4. **克隆专属声音**（一次性）：到「设置」页展开「**克隆我的声音**」面板 →
   录音（对着麦克风读一段，**至少 10 秒**）或上传音频文件 → 提交克隆。
   克隆本身免费；云商规则：克隆声音 **7 天不用会过期**、首次实际合成会收一笔激活费——
   定下要用的就尽快绑到人设里用起来。
5. 人设保存后系统**自动补录**开场白/垫话/词条录音（按新音色重物化），无需手工操作；
   保存成功页面的提示状态即为补录受理回执。

**常见坑**：人设没绑音色 = AI 用默认声，开场白听起来不像「你们公司的人」；克隆后一直没用会被云商删掉，要重新克隆。

## 4. 运营：话术维护（AI 工作站）

**谁**：主管/运营（话务员可改自己名下话术草稿）。**什么时候**：上线新话术、客户反馈某句话讲得不好、合规话术更新时。

### 4.1 从列表进工作台

1. 侧边栏「AI 设置 → **AI 工作站**」。列表每行显示：话术名、**发布状态徽标**、归属（共享/我的/他人）、语言、步数、意图数。
2. 点「**＋ 新建话术**」从零建（填名称/语言/语气，保存后自动进入工作台），或点任意一行进入**工作台**。
3. 工作台共七个页签：**话术流程 · 意图管理 · 变量设定 · 客户意向 · 录音沉淀 · 通话日志 · 场景学习**。
4. 有未应用的修改时，离开工作台或关闭页面都会弹确认，防手滑丢稿。

### 4.2 话术流程：画布改话术

「话术流程」页签默认是**画布**（也可切列表视图批量编辑）：

1. 画布上每一步是一个节点，按场景泳道排布，从左到右就是通话推进顺序。
   **点开任一步节点 → 答法抽屉**，三件东西：
   - **正稿**：这步 AI 主要讲的话（首行；进这步的第一轮念给客户听）。
   - **分支**：一行一条「如果客户说 X → 就答 Y」。Y 的开头可加动作标记：

| 动作 | 效果 | 典型用法 |
|---|---|---|
| 【收线】 | 念完这句后礼貌挂断 | 「我是不是打错电话了→不好意思打扰了【收线】」 |
| 【转人工】 | 通知主管打铃，AI 照常接话不冷场 | 客户情绪激动要求人工 |
| 【跳第 N 步】 | 流程直接跳到第 N 步（从 1 数） | 客户已知道赔偿方案，直接讲办理 |
| 【留本步】 | 不推进流程，原地再答一次 | 客户犹豫，再劝一轮 |

   - **注意**：给 AI 的提醒（如「客户问金额时才报数字」）。
2. **分支条件要写具体**：写客户真实会说的话（如「如果客户说在开会」）；
   条件写得太泛（如「如果客户说话」）会在错误的轮次触发。破坏性动作（【收线】类）系统另有双重保护，
   但条件本身仍应写准。
3. **直念步**：通知/承诺类内容（如赔偿方案）可在列表视图勾「**直念**」——
   AI 进入该步时一字不差照念，防止模型自由发挥改了合规口径。
4. 画布下方「**模板设置**」块：名称/语言/语气/**热词**（提升转写准确率的行业词，逗号分隔，不用写数字串）——
   这块有独立保存按钮。
5. 改完点顶栏「**应用**」保存草稿；「**变量设定**」页签可查所有可用占位符
   （{姓名}{单号}{联系方式} 等）及其取值来源，还能预览替换效果。

### 4.3 发布：改完必须「发布」才生效（重要）

话术有**两态**：你平时改的是**草稿**；AI 通话永远按**已发布版**讲。

1. 草稿改完、应用保存后，点顶栏「**发布**」。
2. 弹窗确认（若有未应用的修改会先提醒你先应用）。
3. 发布成功，徽标从「有未发布改动」（黄）变「已发布」（绿）。

| 徽标 | 含义 |
|---|---|
| 未发布（灰） | 从没发布过，AI 还不会用这套话术 |
| 已发布（绿） | 草稿=发布版，AI 按当前内容讲 |
| 有未发布改动（黄） | 草稿改了但没发布，**AI 仍按旧版讲** |

- 通话进行中改话术/发布都不影响在途那通（建单时已固定快照）。
- 其余页签：
  - 「**意图管理**」= 关键词命中动作（详见 §5.3）；
  - 「**客户意向**」= 挂断归因规则（详见 §7.4）；
  - 「**录音沉淀**」= 这套话术挂的快答词条与录音状态，缺料可直接补；
  - 「**通话日志**」= 按这套话术过滤的通话列表，点进看转写。

**下一步**：改完发布后，用训练模式打一通验证讲法，再去 §5 补配套词条录音。

**常见坑**：改了半天客户侧毫无变化 = 忘了点「发布」——草稿和发布版是两回事。

## 5. 运营：喂 QA 词库（让 AI 秒答高频问题）

**谁**：话务员/运营。**什么时候**：客户反复问同一个问题、AI 每次现场组织答案又慢又不稳时。

### 5.1 原理一分钟

- 客户每说一句，系统先拿话术原文和快答库比对：**措辞对得上（相似度达标）且录了音** → 直接播录音，
  一瞬出声、不花大模型；没录音的词条命中了也不会播，会退回 AI 现场回答。**「录了没」直接决定快不快。**
- 匹配**只认字面措辞**：客户换个说法就命中不了——所以要把各种真实问法都收进库（§5.4 的学习工具就是干这个的）。
- 几种情况**天生不走快答**（不是故障）：

| 情况 | 原因 |
|---|---|
| 问法里带 4 位以上连续数字 | 数字要走路流程捕获，快答不抢 |
| 客户正在报 WhatsApp/微信号码 | 收号步骤锁定，不被词条打断 |
| 语气是拒绝/要收线 | 只收线不应答 |
| 流程已推进或已进收尾 | 收线了不再答 |

### 5.2 快答库日常操作

侧边栏「工作台」组深链「**快答库**」（或从 AI 工作站「意图管理」页签点「问答画布」进入）：

1. **建词条**：右上新建 → 填**问法**（客户原话）、**回答**（标准答案）、语言、
   优先级（数字小=先匹配，默认 10 不用动）、可挂到某套话术的第几步（只在该步生效）→ 保存。
2. **试听 / 补料**：每行有「试听」（听录音效果）和「补料」（生成/重录这条的罐头录音）。
   改过回答文本后**必须重新补料**，否则播的还是旧录音。
3. **常用问题包**：列表顶部可一键导入本语言的常用问答种子（自动挂到话术第 1 步），冷启动先用它；
   已存在的同问法自动跳过，重复导入安全。
4. 优先级 ≠10 的条目列表会显示 P 徽标，方便排查「为什么被别的条目抢了」。
5. 话务员只能改自己的词条；共享条目改动找主管。

### 5.3 画布：挂簇、挂步、配意图

切到「**画布**」视图（顶部「列表 / 画布」切换，画布选模板决定展示哪套话术的骨架）：

- **挂簇（同义变体）**：把同一问题的多种问法条目拖线连到同一条主词条 →
  命中任意变体，都由主词条代表出场，答案还能在簇内轮换不重样。
- **挂步**：把词条拖到画布中话术步骤节点上 → 只在该步生效。
- **意图**：画布里「＋ 意图」建意图卡——关键词若干 + 生效步骤范围（留空=全程）+ 优先级 + 可选判定说明；
  再从意图拖线绑定动作：
  - 绑到快答词条 = 命中关键词就播这条快答（可选「播完跳到第几步」）；
  - 绑跳步 = 命中直接跳到指定步；
  - 绑通知人工 = 命中就给主管打铃（AI 不停话）。
  关键词是**字面包含**匹配，写客户真实会说的话（如「投诉」「退钱」）；判定说明用于补关键词没覆盖的模糊说法。

### 5.4 场景学习：让真实通话帮你喂库（需报表权限）

AI 工作站「**场景学习**」页签，四件事从上到下：

1. **覆盖率与漏网轮**。顶部大数=快路覆盖率（客户提问里多少被快答接住了）；
   下方「漏网轮候选」列出反复出现、AI 每次现场组织的客户问法。每条问法有三种教法（答案可先改再确认）：
   - 「**确认采集**」→ 存成快答词条；
   - 「**确认写入话术**」→ 写成某步的分支行；
   - 「**确认加入意图**」→ 给意图补关键词。
   写入话术的两类只改草稿，**记得去 §4.3 发布**（页面也会提示）。
2. **would-hit 汇总条**：漏网问法里**其实已有词条能接住**的占比。占比高说明库够用、只是没录音——
   先去补录音再采新条，这个数字就会涨。
3. **AI 聚类**：点「生成聚类计划」等数十秒，AI 把最近真实通话的问法分成三组勾选采纳——
   「变体」（挂进现有词条的簇）/「新词条」/「垃圾」。点「采纳选中」入库。
   生成和采纳必须用同一份计划（页面已固定数量参数，别改）；采纳成功后记得补录音。
4. **词条体检**：反向体检已入库的词条，给四类建议——
   - 没人问过、问法带数字串（永远走不了快路）→ 建议**删**；
   - 播了客户又问、反复出现却没用上 → 建议**改答案**。
   点「删掉这条」或「改这条答案」，确认后才动库；删掉的问法以后由 AI 现场回答。

补录音的权限：主管/管理员操作直接生效；话务员操作时若提示需要管理员补录，把词条清单交给主管在设置页触发补录。

### 5.5 日常喂库节奏

通话结束 → 看场景学习有没有新漏网 → 有就采纳 → 采纳完补录音 → 训练模式打一通验证命中。

**常见坑**：①「客户换个问法就命中不了」不是故障——把新问法当变体挂进簇即可；
②改了答案没重录，客户听到的还是旧答案；
③补了录音却不走快答——查是否被更高优先级条目/同簇代表抢了出场（体检详情里会写两种可能）。

## 6. 运营：外呼战役

**谁**：话务员/运营。**什么时候**：按名单批量外呼（回访、通知、营销）。

### 6.1 建战役（三步向导）

1. 侧边栏「**外呼**」→「**新建战役**」向导：
   - **① 基本**：名称 + 选话术（留空=每个对象各自用档案上绑定的话术；选定后整波统一用它）。
   - **② 名单**：从对象库勾选本次要拨的客户。
   - **③ 演练设置**：三组参数（见下表），汇总确认后创建。
2. 创建后状态「**草稿**」，在列表点「**启动**」才开始拨号。

| 参数 | 怎么填 | 规则 |
|---|---|---|
| 外呼时段 | 星期几 + 起止时间，最多 3 组 | 只在时段内拨；**不支持跨零点**（如 22:00-02:00 填了不生效）；与全局时段取交集 |
| 并发 | 同时最多几通，0=不限 | 一轮至多补一通，温和爬升不轰炸 |
| 重拨 | 开关 + 最多次数（1-5）+ 间隔分钟 + 勾选哪些结果要重拨（默认无人接） | 未接通自动回队重拨；**关闭开关并保存=彻底清除重拨**（页面已正确处理，保存后建议复查一次） |

### 6.2 盯着跑

1. 点进战役详情：顶部**进度条**分段显示 完成 / 拨号中 / 通话中 / 无人接 / 拒接 / 失败 / 跳过 / 待拨。
2. 名单明细逐项显示状态（待拨/拨号中/通话中/完成）与结果；点名单项可直达该通通话的工作台看转写。
3. 控制：
   - **暂停**：停拨新号，在途通话不挂；
   - **启动**：继续；
   - **停止**：终态，不能再启动（弹窗确认）；
   - **删除**：运行中拒删（先暂停）；删除连名单一起删，不可恢复。
4. 两通之间有冷却间隔，起拨节奏是匀速的，不是越快越好。

### 6.3 仪表盘口径（看数不看错）

首页仪表盘与战役进度里，「**接通**」= 通话正常结束、且结果不是 无人接/拒接/失败；
「今日」从本地零点起算。AI 判定的客户意向标签（挂断归因）不改变接通口径，也不会引发误重拨。

**演练与真实外呼**：默认演练档由系统模拟虚拟客户接听（试策略零风险，四种虚拟反应：正常聊/不接/秒挂/说一句就走）；
真实外呼需管理员在设置页配置外呼线路（SIP）后才启用。

**下一步**：跑完看 §10 报表复盘接通率；漏接的看名单项结果决定是否补拨。

**常见坑**：对象没填电话 = 名单项直接「跳过」不占重拨；过了时段窗战役会自动停拨，第二天时段内继续——不是卡死。

## 7. 主管：盯盘与打铃

**谁**：主管（主管台在管理面）。**什么时候**：日常盯盘、处理人工求助。

### 7.1 主管台总览

侧边栏「管理 → **主管台**」：所有在途通话一屏卡片——对象、语言、当前讲到话术第几步、时长、客户最近一句，
几秒自动刷新；顶部汇总在途数与暂停数。

### 7.2 打铃：两类待处理事件

页面顶部出现**待处理横幅**并伴随**蜂鸣音**（页面右上开关默认开）：

| 事件 | 触发 | 处理 |
|---|---|---|
| WhatsApp 待对接 | 通话中捕获到客户号码（状态跳变） | 横幅点「进入工作台」→ 复制号码 → 派人加客户 → 工作台里「标记已对接」 |
| 人工求助 | 话术分支【转人工】触发，或话术图「通知人工」动作命中 | 横幅点「**接管**」→ AI 立即停止自动应答，由人工接手该通 |

- 蜂鸣需要你先**点过一次页面**（浏览器不允许网页在没交互前出声）——上班打开主管台后随手点一下空白处即可。
- 打铃只通知、**不打断 AI**：AI 照常兜话，客户那边零空档；接管后 AI 才真正闭嘴。
- 两类待处理在横幅区合并呈现，处理后（标记已对接/接管）横幅自动收起。

### 7.3 卡片操作

每张在途通话卡片上：**静默旁听** / 暂停 AI / 恢复 AI / **接管（人工）** / 转人工 / 挂断（均有确认弹窗）：

- **静默旁听**：只听不说，双方无感知，系统留审计记录（开始/结束都记）；听不到声=点一下页面任意处。
- **接管（人工）**：AI 停止自动应答，人工在工作台接手。接管是「AI 闭嘴 + 你上」，不是把电话桥接到你手机。
- **转人工**：直接结束 AI 通话并标记「已转人工」。
- **挂断**：结束通话并触发结算。

### 7.4 意向规则：让系统自动给通话贴标签

「**会话**」页顶部折叠卡（AI 工作站「客户意向」页签同款）：配置「满足什么条件 → 挂断时打什么意向标签/改什么处置」。

1. 展开卡片 → 新建规则 → 命名、填意向码（如 `callback-later`）、选处置（可留空只打码）。
2. 加条件行：三个下拉——**事实**（全中文）/**比较符**/**数值**。可用事实包括：
   通话时长（秒）、沉默提醒次数、响应异常次数、打断风暴轮数、各类语气累计（确认/提问/拒绝/异议/复读）、
   到达的最大话术步、是否已捕获 WhatsApp、人工求助次数。多条条件**全部满足**才判中；
   按优先级从小到大取第一条命中的规则。
3. 作用域：**全局**（仅主管可建，对所有账号生效）或 **本账号**（话务员也可建，只影响自己账号）。
4. 挂断时系统自动评估：命中的规则会覆盖通话结果标签，工作台/外呼统计随之归类，且不会引发误重拨。

示例：`通话时长 ≥ 120 且 已捕获 WhatsApp = 是` → 意向码 `interested`，用于统计高意向客户。

**常见坑**：蜂鸣不响 = 还没和页面交互过，点一下页面；后台标签页可能漏铃，重要时段保持主管台前台打开，名册与会话列表兜底可见。

## 8. 同传工作台

**谁**：话务员/主管。**什么时候**：跨语言面对面或电话沟通，需要实时翻译。

> 入口：侧边栏「工作台 → **同传**」。旧的「同传」深链页是早期原型，已冻结不再维护，请一律从本入口进。

### 8.1 建会话

1. 选「**我方讲**」和「**对方讲**」的语言（普通话/粤语/English）。**语言对创建后钉死**，选错只能重建。
2. 两把**音色**（可选）：「对方音色」= 对方听到的译文声；「我方音色」= 我方译文声（默认我方译文只出字幕，
   开启双向出声时才用到）。留空跟随系统设置；也可选云端克隆音色。
3. **术语表**（强烈建议填）：专名一行一条，如 `顺丰=SF Express`、`林总`（纯词条=照原样保留）。
   逗号/分号/换行分隔。能同时纠正「听错专名」和「译名漂移」。
4. 点「**创建一体台会话**」进入控制台。

### 8.2 控制台使用

1. 点「**启动传译**」才开始（进房不自动开麦，避免误采）。
2. **字幕**：同页看双向「原文 → 译文」；默认译员视角只看「对方→我」方向，可切。
3. **大字幕**：点「大字幕」开一个可拖动、可全屏、三档字号的置顶浮窗，只显示最新几行，投屏给对方看用。
4. **延迟面板**：显示「对方→我」逐句翻译延迟（最近一句 + 近 8 句平均）。
   正常体感约 2-3 秒；这是「听完整句→译→合成」的物理节奏，不是卡顿。
5. **听对方原声**开关（默认开）：开=像直接通话（对方声音原样进你耳朵，译文叠字幕）；关=纯字幕同传。
6. **设备**：两人各用一支麦克风、各配一路扬声器；系统自动分配并在控制卡上显示每支设备的实时拾音条。
   同一支设备被两侧复用会出红色横幅并拒绝启动传译——按提示换设备（典型的错：两人共用一副蓝牙耳机）。
7. 我方译文播报时系统自动暂让对方麦克风，防止译文被再翻译一遍（串译循环）——听到译文时对方插不上话是设计行为。
8. **离开**=结束整场（两端一起断开），纪要自动沉淀，同 A 线一样可回看转写。

**常见坑**：单边蓝牙耳机被两个人共用 = 双侧串音出垃圾字幕；语言选反了只能退出重建会话；「对方→我」译文默认只出字幕不出声是刻意设计。

## 9. 演示档（仅演示账号）

**谁**：演示者（root）。**什么时候**：给客户演示「端到端云端大模型」的即兴对话效果。

1. 前提：部署侧已开启演示档服务（没开时能建单但无人接，找交付工程师确认）。
2. 「会话」→ 新建通话 → 对象选一个**演示专用对象**、模式选「**演示档（云端 Realtime）**」→ 接通。
3. 特性（与 A 线不同）：
   - **不走路术/快答/沉默提醒/垫话**——云端大模型直接听、直接答，自由对话，适合即兴演示；
   - **300 秒熔断**：到 5 分钟自动告别收线，防止忘挂烧钱；此护栏不可关闭（设 0 也会回落到 5 分钟）；
   - **云端按会话计费**：单通实测约 0.22-0.3 元（随云商价目浮动），用量在后台落账。
4. **红线**：只能绑演示专用假对象——对象名以 `demo-` 开头（或 E2E-、probe 等演示前缀族）；
   绑真实客户档案的通话会被系统**拒绝接入**。这是保护客户数据不出境的强制行为，不是故障。
5. 演示完在会话列表确认该通已结束，不留挂起会话。

**常见坑**：建了单没人接 = 演示服务没开；对象名不带演示前缀被拒 = 红线拦截，换演示对象（先去对象页建一个 `demo-` 开头的假客户）。

## 10. 报表与审计

**谁**：报表=话务员可被授予/默认主管可见；审计=管理面。

### 10.1 报表

侧边栏「运营 → **报表**」：

| 区块 | 看什么 |
|---|---|
| 汇总四卡 | 通话总数 / 活跃通话 / 已结算 / 总轮次 |
| 通话明细 | 逐通结果与轮次 |
| Provider 用量 | 转写次数、大模型 tokens、合成次数等资源消耗 |
| 洞察卡 | 系统自动总结的经营洞察（无权限时此卡不显示，属正常） |

配合 AI 工作站「场景学习」页签（§5.4）看**快路覆盖率**走势：喂库越勤，覆盖率越高、AI 响应越快越省。

### 10.2 审计

侧边栏「管理 → **审计**」：按操作类型或通话编号筛选，查「**谁、什么时候、干了什么**」——
登录、话术发布、词条采纳、主管接管/旁听、外呼操作、短信发送等全留痕，记录不可篡改删除。
有争议时先来这查时间线。

**常见坑**：报表页对话务员默认关闭是权限设计不是坏了；审计是追责依据，别拿它当日志垃圾桶。

## 11. 附录：三分钟排障

遇到问题先对下表，多数 3 分钟内能自解；解决不了再找运维
（运维侧详表见 docs/DELIVERY-MANUAL.md 第 19 节「常见故障速查」）。

| # | 症状 | 三分钟自查 |
|---|---|---|
| 1 | 页面打不开 / 一直「本地服务启动中」 | 服务可能在重启。等半分钟页面会自动恢复并重新加载数据；仍不行通知运维检查服务状态 |
| 2 | 通话/同传没声音 | 先**点一下页面任意处**（浏览器限制网页静默出声）；再查右栏设备卡的扬声器/麦克风选择；确认浏览器没拒掉麦克风权限 |
| 3 | 提示登录失效 / 操作报 401 | 会话过期，重新登录即可；密码忘了找管理员在「员工」页重置 |
| 4 | 改了话术 / 词条「不生效」 | 话术：应用了吗？**发布了吗**（徽标变绿才算生效）？词条：**补录音了吗**？改过答案必须重录 |
| 5 | AI 不开口 / 一直「聆听中」 | 说话即可（直接开口就是打断）；训练模式先讲一句话；检查麦克风是不是选了别的设备（设备卡有实时拾音条） |

其他高频速查：

- 词条命中了却不播录音 = 没物化（§5.1/§5.4 体检详情）。
- 外呼不动了 = 过了时段窗（§6.1），时段内自动恢复。
- 主管蜂鸣不响 = 没点过页面（§7.2）。
- 同传出垃圾字幕 = 两侧共用同一支麦克风/耳机（§8.2），换设备。
- 通话列表少了某通 = 默认只显示最近若干通，点「显示更多」。
