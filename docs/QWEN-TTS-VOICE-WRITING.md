# Qwen3-TTS 正稿写法手册（本地车道真人感指南）

> 面向：在 `/studio`、`/templates` 写 A 线话术正稿的运营/模板作者。
> 适用：**本地 Qwen3-TTS 车道**（Base 克隆 / CustomVoice）。MiniMax 车道标记规则见 `apps/agent/agent_runtime/voice_style.py`。
> 依据：2026-09-28 深度调研（源码级+官方文档+社区实证），证据等级随条标注。

## 一句话铁律

**Qwen3-TTS 不认任何标记。你写的每个字符都会被念出来。**

源码实证：token 表无 breath/laugh/sigh 类特殊 token（33 个 special 全是多模态占位+结构位）；文本进模型是纯字符串拼接，**无解析层、无正则、无文本归一化**。`(breath)`、`[laughing]`、`<#0.3#>` 会被逐字照念——agent 侧已在 `_qwen3_tts_post_frames` 单点剥净（防手滑），但正稿里就不要写。

## 总则三条

1. **不写标记**。`((呼吸))`、`[停顿]`、`<#0.5#>` 一律禁止。
2. **真人感 = 正稿文字（标点+语气词）+ 参考音频（音色与口音）**。instruct 只有 CustomVoice/VoiceDesign 档有，**Base 克隆档没有**（写了不生效，模型限制）。
3. **单次别太长**：≤80-120 字（≈30s 音频）。超长后半段会加速、吞字甚至发散（社区多人实证）。长话术拆步骤。

## 标点 = 停顿梯度（最有效的可控手段）

| 写法 | 效果 | 用法 |
|---|---|---|
| `，` | 短停（换气级） | 一个语义单元一个逗号 |
| `。` | 中停 | 长句拆两句，别堆逗号 |
| `……` | 犹豫/拖音 | 「嗯……我查一下」 |
| `——` | 拖腔/强调 | 「这个——我需要确认下」（未验证，建议 A/B） |
| `？` | 升调 | 提问必写 |
| `、` | 列举停顿 | **数字之间不要用**（号码要连读） |

不要用空格当停顿；不要连续标点 `！！！`。

## 语气词：只写真词

- 普通话：`嗯` `呃` `哦` `哎` `呀` `那个` `就是`
- 粤语：`嗯` `吓` `哦` `呀` `啦` `喇` `咯` `喎` `㗎` `嘅`
- 英文：`Hmm` `Uh` `Well` `Oh`

例：`嗯，我明白您的意思，我这边马上帮您查一下。`／`唔好意思呀，我睇下先。`／`Hmm, let me take a look for you.`

**禁止舞台提示**：`（叹气）`、`(sigh)`、`[笑]`——会被念出来。

## 数字 / 单号 / 号码（Qwen 的 TN 不可靠）

| 场景 | 写法 | 理由 |
|---|---|---|
| 单号/电话/WhatsApp | **逐位汉字**：`一三七一二三四五六七八` | 阿拉伯串会被读成基数词或幻觉（`996→9表6` 社区实证） |
| 金额 | 中文写汉字（`二百蚊`），英文写单词（`two hundred yuan`） | 英文文本里阿拉伯数字混中文读法（`9.9→nine 点 nine 九`） |
| 时间 | `十五点十六分三十六秒` | `15:16:36` 秒位会丢 |
| 间隔号 `·` | 换 `，` | 官方 tip |
| 多音字 | 换同音字 | 拼音标注（`血['XUE3']`）会把字母念出来 |

## 粤语正稿

- 语种**由参考音频决定**（language 无粤语档；agent→sidecar 已自动归一 cantonese→chinese）。正稿写**整段繁体**、别夹普通话书面词。
- 参考音频：粤语母语、**干净收尾**（克隆会回声参考尾部）、**<5s**（流式稳）。
- 想要「抱歉/专业/温柔」的调子 → **录一段该调子的参考**（调子烤在参考里，比任何文字技巧都稳）。

## instruct（仅 CustomVoice / VoiceDesign 档）

句式模板：`用{情绪}的语气，{语速}地{做什么}，{不要 XX}。`

- 抱歉：`用诚恳、略带歉意的语气，语速稍慢地说，像在安抚对方，不要笑。`
- 赔偿：`用冷静、专业、平稳的语气说，吐字清晰，不要拖长音。`
- 抑笑（官方技巧）：情绪指令后加 `但不要笑` / `but without laughing`。

边界：能控情绪/语速/风格；**不能切方言**（说粤语会回普通话）；同一描述多次生成有差异。

## 装配层对照（工程侧）

| MiniMax 车道 | 本地 Qwen3-TTS 车道 |
|---|---|
| `(breath)` 换气注入 | 已剥（`_qwen3_tts_post_frames` 单点）；替代=句界叹词「嗯，」或靠标点 |
| `<#0.3#>` 停顿注入 | 已剥；替代=标点梯度 |
| NATURALNESS_BLOCK prompt | 模型门（"2.8"判据）天然不注入本地车道 |
| 数字顿号剥离 | 保留 |
