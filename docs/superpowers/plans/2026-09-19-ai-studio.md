# AI 工作站（/studio）整合 — 总路线定案与 W1 计划

日期：2026-09-19。前置讨论：本文件 §0 全部为用户拍板项；§1 为双只读探针（web 约束面 + WA/打铃链路面）对 **origin/main f4b1f22** 的实证。主工作树 checkout 陈旧（停 Phase 2 前），一切现状结论以 origin/main 为准。

## §0 决策定案（用户逐条拍板）

1. **转接坐席 = 打铃，不自动让出话轮**。图意图/意向规则命中 → `notify_human` 动作：CP 打标 + 主管台高亮/提醒音 + 审计；AI 照常服务零空档。坐席响应 = 静默旁听（listen）→ 就位后 join+takeover（那一刻 AI 才停）。已有一切链路复用，零 SIP 改动。SIP REFER（电话腿直接转坐席手机号）降为 W5 可选增强，仅当坐席用普通电话接 + trunk 验证支持 REFER 才立项。
2. **WA/微信捕获也打铃**（与 notify_human 共用同一条呈现链）。
3. **发短信进范围（W5）**：webhook provider 先行通链路；正式网关待服务商账号（推荐腾讯云 SMS）。
4. **意图库不新建**：话术图意图（关键词+判据）+ QA 词条已是两层意图资产；工作站做**整合视图 + 自学习采纳流**（挖掘→聚类→一键采纳，W3），不造第三套意图系统。
5. **发布两态采纳（W2）**：保存=草稿，应用=发布即生效；`published_json` 冻结快照 + 建单恒读 published；存量模板默认 published 零变化。
6. **多轮对话 tab 不做**（业务诉求未明）。
7. **录音管理 tab = 罐头资产管理**：QA 罐头 + 垫话资产 + 开场白物化 + pregen + 试听（端点全已有，纯 UI 收编）。
8. **scope 两级：全局（admin 管理）/ 账号级（话务员维护）**；存量 B3 个人归属机制兼容不动。
9. **多场景 = 纯分组**（画布分幕 + 命名跳转目标），不做子图循环引擎——4B 单线推进已实证稳，推进账本与 KV 前缀契约不冒险。

## §5 W2 任务书（2026-09-19 实施，接口冻结）

**§3 W2 原案修订**：不加 `status` 列——**只加 `published_json` 一列**。已发布 ≡ published_json 非空；「有未发布改动」≡ live 与冻结内容不一致（服务端派生布尔）。比双列方案少一列、消灭 status 与快照的状态同步漂移。冻结 payload 九键：`steps_json/graph_json/hotwords/tone_override/opening/core/objection/closing/language`。

### T1（Python/CP+引擎，接口冻结）
1. `conversation_templates.published_json TEXT DEFAULT ''`（models.py + deps `_ensure_column` + repository SQL allow-key/InMemory 缺省）。
2. **一次性回填**：仅当本列在本次启动**刚创建**（`_ensure_column` 建列返回 True 才跑；无返回值则改出返回值）才回填存量行——published_json='' 且任一内容列非空 → 冻结当前 live（保证迁移后运行时读到=原 live，零行为变化）。**不得**每次启动回填（否则新建未发布模板重启即被「视为已发布」）。
3. 派生字段：GET /api/templates 列表与详情行附 `published: bool`、`has_changes: bool`（九键比对）。
4. **机器通道 overlay**：GET /api/templates/{id} 且 `state.machine` 且 published_json 非空 → 解析 payload 覆盖行内九键再返回（agent 装配恒吃冻结版）；人类通道恒 live；列表不 overlay。
5. `POST /api/templates/{id}/publish`：闸链与 PUT 同（gate_page+deny_cross_account+deny_foreign_owner(edit)）→ 冻结当时 live → 审计 `template.publish` → 返回更新行（含派生字段）。PUT 永不触碰 published_json。
6. `flow.py`：`FlowStep.scene: str = ""`（parse_steps 宽容收 "scene" 键；引擎行为零变化）。
7. 测试 `tests/test_template_publish.py` + `python -m compileall` + 目标 pytest；`scripts/dump_postgres_ddl.py` 本地无 PG 则声明跳过（主会话处理）。
