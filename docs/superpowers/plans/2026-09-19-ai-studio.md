# AI 工作站（/studio）整合 — 总路线定案与 W1 计划

日期：2026-09-19。前置讨论：本文件 §0 全部为用户拍板项；§1 为双只读探针（web 约束面 + WA/打铃链路面）对 **origin/main f4b1f22** 的实证。主工作树 checkout 陈旧（停 Phase 2 前），一切现状结论以 origin/main 为准。

## §0 决策定案（用户逐条拍板）

1. **转接坐席 = 打铃，不自动让出话轮**。图意图/意向规则命中 → `notify_human` 动作：CP 打标 + 主管台高亮/提醒音 + 审计；AI 照常服务零空档。坐席响应 = 静默旁听（listen）→ 就位后 join+takeover（那一刻 AI 才停）。已有一切链路复用，零 SIP 改动。SIP REFER（电话腿直接转坐席手机号）降为 W5 可选增强，仅当坐席用普通电话接 + trunk 验证支持 REFER 才立项。
2. **WA/微信捕获也打铃**（与 notify_human 共用同一条呈现链）。
3. **发短信进范围（W5）**：webhook provider 先行通链路；正式网关待服务商账号（推荐腾讯云 SMS）。
4. **意图库不新建**：话术图意图（关键词+判据）+ QA 词条已是两层意图资产；工作站做**整合视图 + 自学习采纳流**（挖掘→聚类→一键采纳，W3），不造第三套意图系统。
5. **发布两态采纳（W2）**：保存=草稿，应用=发布即生效；`published_json` 冻结快照 + 建单恒读 published；存量模板默认 published 零变化。
6. **多轮对话 tab 不做**（业务诉求未明）。
7. **录音管理 tab = 罐头资产管理**：QA 罐头 + 垫话资产 + 开场白物化 + pregen + 试听（端点全已有，纯 UI 收编）。
8. **scope 两级：全局（admin 管理）/ 账号级（话务员维护）**；存量 B3 个人归属机制兼容不动。
9. **多场景 = 纯分组**（画布分幕 + 命名跳转目标），不做子图循环引擎——4B 单线推进已实证稳，推进账本与 KV 前缀契约不冒险。

## §1 探针事实（2026-09-19 双探针，行号以 origin/main 为准）

### web 约束面
- `apps/web/next.config.mjs:5` `output:"export"`，全仓零 `[id]` 动态段 → **工作站详情必须 query param**。先例：`/calls?call=`（calls/page.tsx:102-106 正则）、`/supervisor?listen=`（supervisor/page.tsx:143-146；URL 回写 `history.replaceState` 且 `?` 前带尾斜杠）。
- 导航单点 = `lib/navigation.ts` `NAV_GROUPS`(:50-86)：加一组条目仅改此一处，侧栏/顶栏标题/路由守卫全派生。`NavItem.key` 单可选键；8 键目录（session-context.tsx:12-21）**不扩**——工作站挂 `key:"templates"`（qa 域内容在站内 tab 降级呈现）。
- tab 先例 = 本地 `useState` + button chips（qa 页 view/scopeTab、templates 页 scopeTab）；radix tabs 组件存在但全仓零使用，**不用**。
- 舞台路由 `STAGE_ROUTE_PREFIXES`(:101-105)——工作站不进（常规页保留侧栏）。
- 模板拉取：`api.listTemplates/getTemplate`（api.ts:252-253）；`TemplateRow` 类型在 qa-canvas-view.tsx:23；graph_json 权威读法 = `getTemplate(id).graph_json` → `parseGraphDoc`（lib/qa-canvas.ts:88-99，qa/page.tsx:395-397）。
- 主管台：4s 轮询 active-calls（supervisor/page.tsx:89-93）；payload=call 行**全列**（含 whatsapp_status/customer_whatsapp/escalated_to_human）；已有 `PENDING_WA` 过滤(:14,:169)+`wa-flash` 爆闪横幅(:246-292)+pending 计数卡；**零声音提醒**；`new Audio` blob 先例在 qa/page.tsx:32-36。
- `lib/api.ts` 纯 fetch 轮询，无 WS/SSE。

### WA 捕获链与打铃面
- channel 取值 `{wechat, whatsapp}`（flow.py:436-441 `channel_from_text`；CP main.py:1844-1850 再验兜底）。
- agent 上报：`_report_whatsapp_once`（agent.py:477-499）fire-and-forget + 失败回滚键补报；`_spawn_report`(:2783-2796) 强引用池。CP `POST /api/calls/{id}/whatsapp`（main.py:1813-1879）幂等升级矩阵 → `whatsapp_status`/`customer_whatsapp` + roster upsert（持久面，挂断不消失）+ 审计 `call.whatsapp_captured`。
- `call_sessions` **无通用 flag 列**；`escalated_to_human` 语义被接管钉死、`disposition` 是终态——都不能复用。加列改动面：models.py + deps.py `_ensure_column` + InMemory `create_call` dict 补键 + `scripts/dump_postgres_ddl.py` 重生成（schema-drift CI 门禁强制）。
- 图意图动作枚举 `{play_qa, jump_step}`（flow_graph.py:34-36）；新增 `notify_human` 改动点=解析门/严格校验门/agent 执行第三分支/画布前端自校验；`pick_graph_action` action 无关零改。
- **打铃路径裁决**：v0（W1，纯前端）= active-calls 轮询跳变检测 + 蜂鸣，已知漏铃窗口=①4s 窗内挂断（active-calls 只回 active/paused，行消失跳变从未被观测）②后台标签节流；名册（unclaimed 持久）兜底。根治（W4）= CP 落 `assist_status` 列（方案 B），WA 铃与 notify_human 铃共用「CP 状态列 → active-calls 轮询 → 横幅/蜂鸣」呈现链，`PENDING` 过滤扩展 = WA 态 ∪ assist 态，横幅参数化。

## §2 W1 范围（本期，纯前端零后端）

**T1 导航入口**：`NAV_GROUPS` 新增「工作站」组（放「工作台」组之前），单条目 `/studio`，`key:"templates"`，lucide 图标（如 `Workflow`）。

**T2 `/studio` 模板列表态**（`app/(app)/studio/page.tsx`，无 `?t=` 时）：
- `api.listTemplates` 卡片/行：name、language 徽标、owner 归属徽标（照 templates/qa 页惯例）、steps 步数（parseTemplateSteps）、graph 意图数（parseGraphDoc，仅计数）。
- 点击 → `window.location.assign("/studio/?t=<id>")`。

**T3 工作台壳（同页 `?t=` 态）**：顶栏（模板名+语言+返回列表）+ 五 tab（useState+chips，qa 页同款模式）：
1. **话术流程**：真嵌入编辑器——从 templates/page.tsx 提取 `components/template-editor.tsx`（props: 模板行 + 保存回调），`/templates` 与 `/studio` 双页共用，**行为零变化**（owner 闸、TSV 导入、emotion、hotwords、直念 checkbox 全保留）。
2. **意图与问答**：`getTemplate` 读 graph_json → `parseGraphDoc` 只读摘要（意图清单：关键词/判据有无/scope/priority/once + 绑定动作）+ 步骤脊柱摘要；「打开画布」深链 `/qa/?template=<id>&view=canvas`。qa 页 mount 时补读这两个 query 参数（正则先例同款，~6 行）。
3. **罐头录音**：本模板关联 QA 词条（scope=step 且 template_id 匹配 + 该语言 global 词条计数）的 canned-status 状态清单（读 `/api/qa/canned-status`）+ 整卡跳 qa 页操作（补录/试听在 qa 页做，W1 不复制写路径）。
4. **通话日志**：`api.listCalls` 客户端过滤 `template_id===<id>`，最近在前，显示状态/语言/时长/disposition/WA 状态，行点击深链 `/calls/?call=<id>`。
5. **学习报告**：`/api/reports/script-insights` + `/api/reports/qa-pairs` 只读呈现（scriptInsights 缺 web 封装则补 `api.scriptInsights`）；无 reports 页面键（403）→ 整 tab 隐藏（session.hasPage("reports")）。

**T4 主管台打铃 v0**（supervisor/page.tsx + 可选 globals.css）：
- refresh 回调维护 `prev = Map<call_id, whatsapp_status>`；跳变进入 `offered/captured`（含首帧即 pending 的新行）→ WebAudio 短蜂鸣（oscillator 两音，无需资产）+ 可选 `Notification`（权限已授才发）。
- 顶栏开关「捕获提醒音」，localStorage `bok_supervisor_bell`（默认开；首次交互时初始化 AudioContext 解 autoplay 限制——开关/任意点击手势解锁）。
- 已知漏铃窗口（§1）注释+plan 记录在案，W4 assist 列根治；名册兜底。

**T5 验收**：`cd apps/web && npx tsc --noEmit && npm run build`；手动清单（列表→工作台五 tab→深链往返→templates/qa 页行为不变→supervisor 铃开关）；AGENTS.md + docs/REPO_MAP.md 更新。Python 零改动（pytest 不跑不受影响）。

**W1 明确不做**：话术图画布写路径搬进工作站（W2 随画布重构）、罐头补录/试听复制（W1 深链出）、发布两态（W2）、任何后端。

## §3 W2-W5 契约面概要

- **W2 流程画布+发布两态+场景**：steps_json 步对象加可选 `scene` 字段（parse 宽容）；`conversation_templates` 加 `status`(draft/published，存量默认 published) + `published_json`（冻结快照）两列（`_ensure_column` + dump_postgres_ddl 重生成 + Supabase 引导件重跑）；建单装配链恒读 published_json；campaign 模板选择过滤 published；画布=steps 节点化 + 答法抽屉 + 图边合流（QA 画布三层范式复用）。
- **W3 变量+自学习闭环**：变量定义页（占位符扫描+对象字段预览渲染）；`tts-mine --cluster` 逻辑提为 CP 端点（mine/adopt），工作站「学习」tab 加候选→一键采纳（variant 继承答案入库/new 走质量闸）；两级 scope。
- **W4 意向规则引擎+notify_human**：`intent_rules` 新表（确定性条件：到达步/时长/超时次数/verdict 计数/WA captured → 意向码+标签+优先级）+ agent per-call verdict 账本 + 挂断结算单点评估（纯函数）→ disposition/dashboard `_ANSWERED_EXCLUDED`/campaign 重拨三消费点同步 + audit `intent.*`；`call_sessions` 加 `assist_status` 列 + `POST /api/calls/{id}/assist` 端点（照 report_whatsapp 骨架）+ 图意图 `ACTION_NOTIFY_HUMAN` 第三分支（上报成功才烧 once；不 StopResponse 不抢话为本档默认，安抚语可配置）+ supervisor 呈现链 pending=WA∪assist、横幅参数化。
- **W5 短信+REFER+卫生**：settings 通知域（webhook provider 插件位+审计 sms.send+变量替换）；SIP REFER 验证试点；音色数据源统一、试听逻辑统一、孤儿 API（supervisorJoin/settle/changeMyPassword）收编。

## §4 纪律
- 每期独立 PR、CI 绿本地合；探针先行惯例保持；改 web 必跑 tsc+build；后端期必跑 pytest + 引导件重跑回环。
