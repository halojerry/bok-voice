**Goal:** 用本仓三语真化测试音频实测 TEN VAD 与现役 silero VAD 的「语音结束判定时刻」差异，回答「VAD 层能否再抠出 100-300ms eou 延迟」。

### Task 3: A/B 脚本

**Files:**
- Create: `scripts/ab_vad_ten_vs_silero.py`

- [ ] **Step 1: 写脚本**（核心结构如下，ten_vad 侧按 Task 2 探明的真实 API 落地）

```python
#!/usr/bin/env python3
"""TEN VAD vs silero 语音端点 A/B：同音频对比 speech 段 END 时刻/分段数/RTF。"""
from __future__ import annotations
import wave, sys, time
import numpy as np

SR = 16000

def load_wav(path: str) -> np.ndarray:
    with wave.open(path, "rb") as w:
        assert w.getframerate() == SR, f"{path}: {w.getframerate()}Hz != 16k"
        pcm = np.frombuffer(w.readframes(w.getnframes()), dtype=np.int16)
    return pcm.astype(np.float32) / 32768.0

def run_silero(pcm: np.ndarray) -> list[dict]:
    from livekit.plugins import silero
    vad = silero.VAD.load()  # 现役参数: min_silence 由 session 侧配,此处用默认流式
    stream = vad.stream()
    events = []
    frame = 512  # silero 512 样本=32ms@16k
    t0 = time.perf_counter()
    for i in range(0, len(pcm) - frame + 1, frame):
        events.extend(stream.push(pcm[i : i + frame]))
    events.extend(stream.flush())
    wall = time.perf_counter() - t0
    segs = [
        {"end_ms": e.samples_index / SR * 1000, "dur_ms": e.speech_duration * 1000}
        for e in events if e.type.name == "END_OF_SPEECH"
    ]
    return {"segments": segs, "rtf": wall / (len(pcm) / SR)}
```

ten_vad 侧同构：逐帧 push、收集 END 事件（TEN VAD hop 按 Task 2 探明值，事件时间=帧号×hop/SR）。输出对比表：每文件两引擎的 `segment 数 / 各段 end_ms / RTF`，汇总 `median(end 差值)`、`过劈率（ten 段数 - silero 段数）/ silero 段数`。
