# 全功能用户视角端到端测试计划（2026-09-09）

交付前扫清「半成品」：12 个页面、60+ 可交互功能逐个点击实测。三轨并进。

## 轨 A：浏览器逐页实测（browser-use 驱动 Chromium → :3000）

每页按清单操作，记录 PASS / FAIL / 受限（带复现步骤）。测试数据统一 `QA-` 前缀，测后清理；设置保存一律改后复原。

## 轨 B：真机链路 E2E + 专项

1. 既有全套补跑：三语 E2E（真 token）、barge_in、edge_cases、interpret、4 路并发压测。
2. **「拼多多→多多」漏字专项**：渲染音频念「我在拼多多买的」（cantonese/zh 各一版+快速连读版），断言转写含「拼多多」全文——结果直接指认漏字根因（句级提交切碎 vs ASR 精度）。
3. **LLM 复读专项**：连续两轮相似应承，断言两轮回复不逐字相同（先固化用例再修）。
