# 合规版三语话术模板（2026-10-03）

源材料：`合规话术.rtf` B 稿「集运包裹丢失｜三语客服实战话术（全场景真实版）」
（8 节 23 场景 + 收尾，三语齐）。本目录是其 **模板化产物**：`hegui-zh.json` /
`hegui-cantonese.json` / `hegui-en.json`，每份 = 一个 `POST /api/templates` 的
完整载荷（`steps_json` 存人可编辑的数组，装载器转字符串契约）。

## 装载

```bash
./pkgruntime-aside/python/bin/python3.12 scripts/load_compliant_templates.py            # dry-run
./pkgruntime-aside/python/bin/python3.12 scripts/load_compliant_templates.py --apply
# 发布（冻结九键 + 罐头 pregen；pregen 需 TTS 可用——MiniMax 恢复后再开）：
./pkgruntime-aside/python/bin/python3.12 scripts/load_compliant_templates.py --apply --publish
```

- 幂等：按 name 匹配，存在则 PUT；**不动同名以外任何模板**（并存策略）。
- 命名不含 e2e/probe → 探针 `erc.create_call` 的自动选模会优先吃到新模板
  （按语言匹配），旧生产模板保留给现网对象。

### 新增/微调句（三语各一处，全部合规底线内）

- **步3 正稿**（新增）：平台确认问句 + 引导找未签收订单。B 稿无平台步（原生产
  六步有），按 Ethan 早前拍板「平台步需要另补」补写；不含任何承诺。
  - zh：「为了帮您核对这件包裹，麻烦您在购物平台找一下对应的未签收订单。也请问您还记得是在哪个平台下的单吗——拼多多、淘宝还是京东呢？」
- **步4 前缀**：仅加「关于赔付这一块：/關於賠償方面：/About the compensation:」
  作引导（场景10 原句是应答体，直接当正稿读缺个由头）。
- **步6 正稿**（新增）：独立可念的异议引导句（原场景18 句是「让您这么生气」的
  应答体，不适合当步骤正稿；场景18 原句保留为分支）。三语均只承诺「记录+提交
  主管+官方投诉热线」，与场景18 同口径。
- **注意行**（每步 1-2 条）：按 B 稿自述合规底线提炼（官方渠道/不虚构条例/
  不承诺倍数/不剥夺维权权利/到账口径按「X 个工作日」/丢件原因以调查结论为准）。

### 候选动作标注（**未启用**，待拍板）

- 场景3（没空改约）→ 候选 `【收线】`（礼貌收线）；现为纯文本，礼貌收尾由 LLM 承接。
- 场景18（要主管）→ 候选 `【转人工】`（打铃不抢话，接 W4 notify_human 链）；
  现为纯文本。

  标记，不念出声）。
